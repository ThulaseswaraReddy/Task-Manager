# 📝 Task Manager (MERN Stack)

A simple Task Manager web application built using the MERN stack (MongoDB, Express, React, Node.js).
Users can register, login, and manage their daily tasks and after completion of their task can delete the task.

## 🚀 Features
```
🔐 User Authentication (Signup & Signin)
➕ Add Tasks
❌ Delete Tasks
📋 View Tasks
💾 Data stored in MongoDB
🎨 Simple and clean UI using Bootstrap
```

## 🛠️ Tech Stack
```
* *Frontend:* React, Bootstrap, Axios
* *Backend:* Node.js, Express
* *Database:* MongoDB (Atlas / Compass)
* *Authentication:* bcrypt
```
